# BuildAI Reviews — Growth Campaign Kit

Working documents for the SEO/GEO campaign. Kept **outside** `buildai/` on
purpose: nothing in this folder is ever deployed to the live site.

| File | What it is |
|---|---|
| `outreach-templates.md` | Copy-paste templates: journalist responses (Qwoted/SourceBottle/Featured), guest-post pitches, directory submissions, mention reclamation, follow-ups |
| `content-calendar.md` | 6-month, 18-page publishing plan with target queries, evidence requirements, and the weekly routine |
| `weekend-test-protocol.md` | Structured protocol for the original-research weekend: same brief across all 5 builders, timings, screenshots, scorecards aligned to the site's methodology weights |

## The strategy in one paragraph

The site is technically ready; rankings now come from **authority**: real links
(earned via journalist platforms, the data study, directories, and local SA
angle content), consistent publishing (2–3 pages/month from the calendar), and
evidence upgrades from the testing weekend. No bought links, no schemes —
Google now penalizes those at domain level, and the whole build is designed
around being provably trustworthy instead.

## Order of operations

1. Deploy current site to Netlify (done when zip is uploaded)
2. Domain decision → Search Console + Bing Webmaster Tools
3. Directory submissions (template #3)
4. Daily journalist-platform responses (template #1)
5. Month 1–2 calendar pages
6. Testing weekend → Month 3 data study → pitch it
